VIBE TALK - Realtime Chat App (MERN + Socket.io)
VIBE TALK is a modern real-time chat application built using the MERN Stack (MongoDB, Express, React, Node.js) with Socket.io for bi-directional communication. It features live 1:1 messaging, typing indicators, online status, image uploads, authentication, and a fully responsive UI.

🚀 Features
🔒 JWT Authentication – Secure login/signup
💬 1:1 Realtime Messaging – Powered by Socket.io
✍️ Live Typing Indicators
🟢 Online/Offline User Status
🖼️ Profile & Chat Image Uploads – Integrated with Cloudinary
🗂️ MongoDB + Mongoose – Robust schema-based database
⚡ Redux Toolkit – Smooth state management
🎨 Tailwind CSS – Beautiful, fully responsive design
📱 Mobile & Desktop Ready

🛠️ Tech Stack
React.js, Redux Toolkit, Node.js, Express.js, Socket.io, MongoDB Atlas, Mongoose, Tailwind CSS, Render (Frontend & Backend API)
